04Structural systems

Hot rolled or cold rolled?

There isn't one steel-frame system that's right for every building. Size, span, height, loading and intended use all influence the most appropriate solution.

CR — System A

Cold rolled

Galvanised C & Z sections

Structure
Lightweight structural system
Economy
Highly economical for suitable projects
Typical use
Workshops and smaller units
Delivery
Efficient manufacture and installation
VS

HR — System B

Hot rolled

Universal beams & columns

Structure
Heavier structural steel
Economy
Suited to larger, more demanding projects
Typical use
Industrial, warehouse and large commercial
Performance
Greater span, height and loading flexibility

Wedgewood provides both — so the building requirement determines the structural solution.
